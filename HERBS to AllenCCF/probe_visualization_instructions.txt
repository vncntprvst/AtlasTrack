Probe Visualization Instructions
================================

This guide explains how to use probe_visualization.py after you finish annotating
probes in HERBS. The script makes an interactive 3D HTML file showing probe
locations in the Allen CCF, optional brain-region meshes, and optional unit/effect
points from a unit table.


Before You Start
----------------

Install the required Python packages if you have not already:

    pip install brainglobe-atlasapi plotly numpy

The first time you use the Allen atlas, BrainGlobe may need to download it.

The script is located here:

    probe_visualization.py

Run commands from the folder that contains the script, or provide the full path to
the script.


Option 1: Use HERBS .pkl Probe Files
-----------------------------------

Use this option if you want to plot the probe trajectories directly from HERBS
pickle files.

1. Export or save your probe .pkl files from HERBS.

2. Put all probe .pkl files for the visualization in a single folder.

3. Name each file using this format:

    animalID_probeNumber.pkl

Examples:

    MouseA_1.pkl
    MouseA_4.pkl
    MouseA_probe1.pkl
    MouseA_probe4.pkl
    Rat27_probe_01.pkl
    Rat27_probe_04.pkl

The animal ID can be anything, as long as it is consistent. It does not need to
start with NVnpg.

4. Run:

    python probe_visualization.py --probe-dir /path/to/probe_pickle_folder

This creates:

    probe_visualization.html

inside the probe pickle folder, unless you choose another output path.


Option 2: Use a Probe Coordinate CSV
-----------------------------------

Use this option if you want to manually enter insertion and terminus coordinates
for each shank.

Create a CSV with one row per shank. The script accepts either Allen CCF columns
or bregma/midline-relative columns.


Recommended Allen CCF CSV columns
---------------------------------

Use these columns if your insertion and terminus points are already in Allen CCF
microns:

    Animal
    Shank
    Rotation (degrees)
    Insertion AP CCF
    Insertion ML CCF
    Insertion DV CCF
    AP angle
    ML angle
    Terminus AP CCF
    Terminus ML CCF
    Terminus DV CCF

Notes:

- Animal is the animal ID. It can be any unique label, such as MouseA, Rat27,
  NVnpg06, etc.
- Shank is the shank number.
- Rotation (degrees) controls the orientation of the probe face. If missing, the
  script uses 270 degrees.
- AP angle and ML angle are allowed in the CSV for record keeping, but the script
  plots the probe using the insertion and terminus coordinates.
- Coordinates should be in microns.

Run:

    python probe_visualization.py --csv-path /path/to/probe_coordinates.csv


Bregma/midline-relative CSV columns
----------------------------------

You can also use columns like:

    Animal
    Shank
    Rotation (degrees)
    Insertion AP
    Insertion ML
    AP angle
    ML angle
    Terminus AP
    Terminus ML
    Terminus DV

In this format:

- Insertion AP and Terminus AP are relative to bregma.
- Insertion ML and Terminus ML are relative to midline.
- Terminus DV is depth in microns.
- The script converts these values into Allen CCF coordinates.

If the script guesses the coordinate system incorrectly, force the interpretation:

    python probe_visualization.py --csv-path /path/to/probe_coordinates.csv --coordinate-system ccf

or:

    python probe_visualization.py --csv-path /path/to/probe_coordinates.csv --coordinate-system bregma


Choosing the Output HTML File
-----------------------------

Option A: Set the output path in the command:

    python probe_visualization.py --csv-path probes.csv --output /path/to/my_plot.html

Option B: Set the output path inside the code.

Near the top of probe_visualization.py, find:

    DEFAULT_OUTPUT_HTML = None

Change it to:

    DEFAULT_OUTPUT_HTML = "~/Desktop/my_probe_plot.html"

The command-line --output option always overrides DEFAULT_OUTPUT_HTML.


Choosing Brain Regions to Plot
------------------------------

By default, the script plots:

    root
    SSp-bfd
    SSp-ul
    SSp-ll
    MOp
    PTLp
    VIS

To choose a different set of regions, use:

    python probe_visualization.py --csv-path probes.csv --brain-regions root,MOp,VIS

You can also customize labels, colors, and opacity:

    python probe_visualization.py --csv-path probes.csv \
        --region root:Whole_brain:#9aa7ba:0.20 \
        --region MOp:Motor:#ffff33:0.15 \
        --region VIS:Visual:#17becf:0.15

The format is:

    ACRONYM:Label:Color:Opacity


Optional Shank Interpolation
----------------------------

If you only have measured shanks 1 and 4, the script can create shanks 2 and 3.

The interpolation rule is:

- Shank 2 is 1/3 of the way from shank 1 to shank 4.
- Shank 3 is 2/3 of the way from shank 1 to shank 4.
- This is done in AP, ML, and DV at every point along the probe.

Run:

    python probe_visualization.py --csv-path probes.csv --interpolate-shanks

or:

    python probe_visualization.py --probe-dir /path/to/probe_pickle_folder --interpolate-shanks

To interpolate only selected animals:

    python probe_visualization.py --csv-path probes.csv \
        --interpolate-shanks \
        --interpolate-animal-ids MouseA,MouseB

By default, interpolated shanks replace existing shanks 2 and 3 for animals that
have shanks 1 and 4. To keep existing shanks 2 and 3 too:

    python probe_visualization.py --csv-path probes.csv \
        --interpolate-shanks \
        --keep-existing-interpolated-shanks


Optional Unit or Effect Point Overlay
-------------------------------------

The script can plot individual unit/effect points on the probe face.

Your unit/effect CSV should include:

    rec_name
    tt_idx
    depth
    x_position
    effect column of interest

The script also accepts x_pos instead of x_position.

Example columns:

    rec_name,tt_idx,depth,x_position,mass_effect

or:

    rec_name,tt_idx,depth,x_pos,my_effect

Column meanings:

- rec_name is the recording name. It should start with the animal ID used in the
  probe CSV or pkl filename.
  Example: if the animal ID is MouseA, recording names like MouseA_20260401 will
  match MouseA.
- tt_idx is the shank number.
- depth is the unit depth from the probe insertion surface, in microns.
- x_position or x_pos is the electrode x position.
- The effect column is any numeric value you want to visualize.

If the unit table has a use column, the script only plots rows where use == 1.
To include all rows:

    --include-unused-units

Example using mass_effect:

    python probe_visualization.py --csv-path probes.csv \
        --feature-csv unit_table.csv \
        --feature-column mass_effect

Example using a different effect:

    python probe_visualization.py --csv-path probes.csv \
        --feature-csv unit_table.csv \
        --feature-column my_effect \
        --feature-transform none

Feature color options:

- --feature-transform log2-ratio is useful for ratio effects centered around 1,
  such as mass_effect.
- --feature-transform none is better for arbitrary signed or already-scaled
  effects.
- --feature-min and --feature-max can filter which raw effect values are plotted.

Example:

    python probe_visualization.py --csv-path probes.csv \
        --feature-csv unit_table.csv \
        --feature-column mass_effect \
        --feature-min 2


Common Full Examples
--------------------

Plot a coordinate CSV with default regions:

    python probe_visualization.py --csv-path probes.csv

Plot HERBS pickle files with interpolated shanks:

    python probe_visualization.py --probe-dir /path/to/probe_pickle_folder --interpolate-shanks

Plot only selected animals and shanks:

    python probe_visualization.py --csv-path probes.csv \
        --animal-ids MouseA,MouseB \
        --shanks 1,4

Plot a CSV with unit/effect points:

    python probe_visualization.py --csv-path probes.csv \
        --feature-csv unit_table.csv \
        --feature-column mass_effect \
        --output ~/Desktop/probe_visualization_with_units.html

Plot only selected brain regions:

    python probe_visualization.py --csv-path probes.csv --brain-regions root,MOp,VIS


Troubleshooting
---------------

If no probes appear:

- Check that animal IDs are consistent across files.
- Check that shank numbers in the CSV or filenames are correct.
- If using feature points, check that rec_name starts with the same animal ID used
  in the probe inputs.

If the probes look flipped:

- For .pkl files, try changing HERBS flip options:

    --flip-ml / --no-flip-ml
    --flip-ap / --no-flip-ap
    --flip-dv / --no-flip-dv

If CSV coordinates look wrong:

- Try forcing the coordinate system:

    --coordinate-system ccf

  or:

    --coordinate-system bregma

If the output file is not where expected:

- Check whether --output was used.
- Check DEFAULT_OUTPUT_HTML near the top of probe_visualization.py.
- If neither is set, the script saves probe_visualization.html next to the input
  CSV or probe folder.
